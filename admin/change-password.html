Зміна пароля адмін-панелі

Впишіть новий логін і пароль — отримаєте два готові рядки, які треба вставити у файл admin/admin-auth.jsx.

  1. Скопіюйте рядки вище
  2. На GitHub відкрийте admin/admin-auth.jsx → олівець (Edit)
  3. Знайдіть рядки 8 і 9 (починаються з const CREDS та const PASSWORD_HASH) і замініть їх на скопійовані
  4. Commit changes

Пароль ніде не зберігається у відкритому вигляді — лише його SHA-256 хеш. Проте сайт статичний, тому хеш присутній у коді сторінки: це захист від випадкових відвідувачів, а не від досвідченого зламника. Для справжнього захисту потрібен сервер.
