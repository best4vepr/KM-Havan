# Гавань — сайт + адмін-панель

Повний комплект для заливки в репозиторій GitHub.

## Вміст

```
index.html            головна сторінка сайту
layout.jsx            шапка, гамбургер-меню, герой, футер
sections.jsx          секції: переваги, новий квартал, схеми, галерея, контакти
content.js            читання опублікованого content.json + локальних правок
styles.css            підключає tokens/
tokens/               кольори, типографіка, відступи, тіні
ds-bundle.js          UI-компоненти
assets/               логотипи, схеми ділянок
assets/photos/        24 фото сайту
admin/                адмін-панель (вхід: admin / admin)
.nojekyll             вимикає обробку Jekyll
.github/workflows/    публікація GitHub Pages без Jekyll
```

## Повна перезаливка

**Найпростіше — новий чистий стан:**

1. У репозиторії видаліть старі файли й папки (кожну: відкрити → «...» → **Delete directory** → Commit).
2. **Add file → Upload files** → перетягніть **весь вміст цієї папки** (не саму папку, а файли й підпапки всередині) → **Commit changes**.
3. **Settings → Pages → Source** = **GitHub Actions**.

**Файли, що починаються з точки, веб-завантажувач GitHub пропускає.** Створіть їх вручну:

- `.nojekyll` → **Add file → Create new file**, ім'я `.nojekyll`, вміст порожній → Commit.
- workflow → **Add file → Create new file**, ім'я `.github/workflows/deploy.yml`, вставити вміст однойменного файлу з цієї папки → Commit.

Через 1–2 хвилини:
- сайт — `https://<логін>.github.io/<репозиторій>/`
- адмінка — `https://<логін>.github.io/<репозиторій>/admin/`

## Адмін-панель

Вхід: **admin** / **admin** — обов'язково змініть пароль.

1. Згенеруйте SHA-256 хеш нового пароля (напр. на emn178.github.io/online-tools/sha256.html).
2. У `admin/admin-auth.jsx` замініть значення `PASSWORD_HASH`.
3. Логін змінюється там же — у рядку `CREDS`.

### Як публікувати зміни

- **«Зберегти»** — зміни видно лише в цьому браузері (швидкий перегляд).
- **«Опублікувати»** — завантажує `content.json`. Залийте його в корінь репозиторію → зміни побачать усі, включно з телефонами.

### Фото через адмінку

Фото, замінене в адмінці, вбудовується у `content.json` цілим файлом і швидко роздуває його до десятків мегабайт.

**Надійніше:** залийте зображення в `assets/photos/` під тим самим іменем, що й старе (напр. `hero-desna.jpg`) — воно заміниться саме собою. Адмінку використовуйте для текстів, посилань і налаштувань вигляду.

## Важливо

- **Фото оптимізовані для веба** (~9 МБ разом). Не замінюйте їх важкими оригіналами з камери — GitHub не завантажить папку, а сайт буде довго відкриватися.
- **Потрібен інтернет:** шрифти, React/Babel/Lucide та Google-карта вантажаться з CDN.
- Якщо після заливки бачите стару версію — відкрийте в приватному вікні (кеш).

## Мобільна версія

Адаптовано під телефони: гамбургер-меню, одноколонкові блоки, карусель по 1 картці, схеми показуються повністю, збільшені тап-цілі.
